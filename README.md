# NETMONITOR – Network Device Status Simulator

## Project Overview
NETMONITOR is a Java Swing desktop application designed to manage and simulate the monitoring of network devices through a graphical dashboard.

## Features
- Add new network devices
- Edit existing device information
- Delete registered devices
- Search devices
- Manage online/offline status
- Display total device statistics
- Validate IP addresses
- Save device information locally
- Load previously saved devices

## Technologies Used
- Java 21
- Java Swing
- AWT
- Object-Oriented Programming
- File Handling
- Visual Studio Code

## Application Type
Desktop GUI Application

## Project Purpose
The purpose of this project is to understand Java programming, GUI development, event handling, and basic network device management.

## Future Enhancements
- Real network connectivity testing using ping
- MySQL database integration
- Device monitoring history
- Network performance statistics
- User authentication
